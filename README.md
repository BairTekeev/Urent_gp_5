## Система с использованием глубокого обучения для приоритизации пациентов с подозрением на тяжелое заболевание

## Основная цель проекта

Разработать прототип AI-системы, которая по клиническим данным пациента и изображению кожного образования помогает определить приоритет обращения к врачу-дерматологу.

Наш проект не заменяет врача,а также не ставит окончательный диагноз. Его задача лишь помочь медицинской организации быстрее выделять потенциально более опасные случаи и эффективнее распределять ресурсы врачей-дерматологов.

## Бизнес-проблема

В медицинской практике пациенты часто попадают в очередь по принципу «кто раньше записался», а не по уровню потенциального риска.

Из-за этого возникают несколько проблем:

- пациенты с потенциально опасными образованиями могут ждать консультации слишком долго (
- врач тратит одинаковое внимание на случаи разной срочности
- задержка диагностики онкологических заболеваний может ухудшать прогноз лечения

## Как поможет AI?

В проекте используются два модуля глубокого обучения.

Сверточная нейронная сеть анализирует изображение кожного образования и определяет его вероятный тип.

Полносвязная нейронная сеть анализирует клинические данные пациента и определяет уровень приоритета обращения.

После этого результаты двух моделей могут использоваться вместе: если хотя бы один модуль показывает высокий риск, пациент получает более высокий приоритет для осмотра врачом.

Логи, артефакты и инфа о моделях тут: https://wandb.ai/bair_tekeev-techmed/GP_5_Skin_DL?nw=nwuserbair_tekeev

## Как решение встраивается в бизнес-процесс

1. Пациент заполняет анкету и загружает фото кожного образования.
2. Система очищает и преобразует данные.
3. Табличная модель оценивает клинический риск по симптомам и данным пациента.
4. CNN-модель анализирует изображение образования.
5. Итоговый модуль формирует уровень срочности обращения.
6. Пациенты высокого риска направляются врачу быстрее.
7. Врач принимает финальное медицинское решение.

## Чуть подробнее про модуль компьютерного зрения

**На вход** подается изображение кожного образования.

**На выходе** модель определяет один из классов кожного образования:

- `akiec`
- `bcc`
- `bkl`
- `df`
- `mel`
- `nv`
- `vasc`

Эти классы используются для оценки потенциальной опасности случая и дальнейшей приоритизации обращения.

**Рассмотрены несколько моделей:**

- базовая CNN;
- CNN + BatchNorm + Dropout;
- AlexNet;
- EfficientNet-B0.

## Чуть подробнее про модуль полносвязной нейронной сети

**На вход** подаются клинические и анкетные признаки пациента:

- возраст;
- локализация образования;
- наличие зуда;
- рост образования;
- наличие боли;
- изменение образования;
- кровоточивость;
- возвышение образования над кожей.

**На выходе** модель определяет уровень приоритета обращения:

- 0 - стандартный приоритет;
- 1 - повышенный приоритет;
- 2 - высокий приоритет.


**Рассмотрены несколько моделей:**

- базовая FCNN;
- глубокая FCNN с ReLU;
- глубокая FCNN с GELU;
- FCNN + BatchNorm + Dropout.

Такое сравнение позволяет понять, как глубина сети, функция активации и регуляризация влияют на качество определения приоритета пациента.

## Что является результатом проекта

Результатом проекта является мвп системы, которая:

- принимает клинические данные пациента;
- принимает изображение кожного образования;
- оценивает риск по табличным признакам;
- классифицирует изображение с помощью CNN;
- помогает врачу быстрее увидеть потенциально опасные случаи.

## Основные метрики

Для оценки моделей используются:

- accuracy;
- precision;
- recall;
- F1-score;

## Бизнес-ценность

SkinTriage AI помогает медицинской организации:

- быстрее выделять пациентов высокого риска;
- снижать вероятность задержки консультации для потенциально опасных случаев;
- уменьшать нагрузку на первичную сортировку;
- стандартизировать процесс обработки обращений;
- повысить прозрачность принятия решений;
- эффективнее использовать время врача.
