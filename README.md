# Проект Urent_gp_5 
Система с использованием глубокого обучения для проверки завершения поездок в сервисах кикшеринга

## Основная цель проекта 
Быстро выявлять потенциально проблемные завершения поездок и оптимизировать работу модераторов

## Бизнес-проблема
Все больше приходит жалоб на неправильную парковку  
Трата значительных ресурсов на обработку завершенных поездок  
Ухудшение клиентского опыта 
## Как поможет AI?  
Сверточная нейронная сеть определяет праивльность парковки по фото после завершения парковки  
Полносвязаная нейронная сеть данные поездки и исторические данные о жалобах для оценки риска завершения поездки с проблемами  
## Чуть подробнее про модуль компьютерного зрения
**на вход** подается фото самоката после заверешения поездки   

**на выходе** корректная/некорректная парковка  

**рассмотрены три модели** - CNN, CNN+dropout+batchnorm, ResNet  

## Чуть  подробнее про модуль полносвязанной нейронной сети   
**на вход** подаются:   
- длительность поездки  
- расстояние поездки  
- время завершения  
- район старта    
- район финиша   
- статистика жалоб

**на выходе** риск появления жалобы  

**рассмотрены три модели** - FCNN, глубокая FCNN, FCNN+dropout+batchnorm
